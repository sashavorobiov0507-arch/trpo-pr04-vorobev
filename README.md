# Практическая работа №4 — PHP: формы и обработка запросов

Небольшое PHP-приложение без MVC: список сотрудников из CSV, форма заявки с серверной валидацией и фильтр по отделу

## Технологии
PHP 8+, HTML. Расширение mbstring должно быть включено

## Запуск
php -S 127.0.0.1:8080 -t public

Адрес: http://127.0.0.1:8080

## Структура
- public/index.php — страница: форма, фильтр, таблица
- src/functions.php — функции: e, parseEmployee, loadEmployees, validateInput, filterEmployees
- data/employees.csv, data/form_cases.json — исходные данные

## Как проверить
1. Откройте страницу, выберите отдел и нажмите «Фильтр» — в таблице останутся сотрудники этого отдела
2. Отправьте пустую форму — появятся ошибки возле полей
3. Имя «Иван» и стаж -2 — ошибка стажа, имя в поле сохраняется
4. Имя «Иван», стаж 4, корректные email и отдел — сообщение «Заявка принята»

## GET и POST
GET передаёт данные в адресе страницы и подходит для фильтров. POST передаёт данные в теле запроса и подходит для форм, которые что-то отправляют

## htmlspecialchars
Превращает символы вроде < и > в безопасный текст, чтобы введённая строка не исполнялась как HTML-тег

## Путь данных
Форма (POST) -> $_POST -> trim -> validateInput -> массив ошибок -> html с ошибками и сохранёнными значениями, данные из CSV: loadEmployees -> parseEmployee -> фильтр -> таблица
